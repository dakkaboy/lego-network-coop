# LEGO Network Co-op

[English](README.md)

Моды для сетевого кооператива в играх LEGO на Windows.

| Игра | Статус | Задачи | Скачать |
| --- | --- | --- | --- |
| [LEGO Star Wars III: The Clone Wars](games/lego-star-wars-iii/README.ru.md) | 0.0.2 alpha | [Прогресс и задачи](https://github.com/dakkaboy/lego-network-coop/milestone/1) | [Релиз на GitHub](https://github.com/dakkaboy/lego-network-coop/releases/tag/v0.0.2) |
| LEGO Star Wars: The Complete Saga | В планах | [Раздел](https://github.com/dakkaboy/lego-network-coop/milestone/2) | — |
| LEGO Indiana Jones: The Original Adventures | В планах | [Раздел](https://github.com/dakkaboy/lego-network-coop/milestone/3) | — |
| LEGO Indiana Jones 2: The Adventure Continues | В планах | [Раздел](https://github.com/dakkaboy/lego-network-coop/milestone/4) | — |

У каждой игры своя папка в `games/` и отдельная сборка. Адреса в исполняемом файле, перехватчики, состояние игры, сетевой протокол и упаковка хранятся в папке игры. Общий код выделяем, когда он нужен второй игре.

## Участие в разработке

Можно исправить ошибку, улучшить сетевой код или добавить поддержку другой игры LEGO. Для обсуждения изменений откройте issue, а для готовой правки отправьте pull request. Для новой игры создайте отдельную папку в `games/`.
