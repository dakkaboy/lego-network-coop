# LEGO Network Co-op

[Русский](README.ru.md)

Windows network co-op mods for LEGO games.

| Game | Status | Tasks | Download |
| --- | --- | --- | --- |
| [LEGO Star Wars III: The Clone Wars](games/lego-star-wars-iii) | 0.0.6 alpha | [Progress and tasks](https://github.com/dakkaboy/lego-network-coop/milestone/1) | [GitHub release](https://github.com/dakkaboy/lego-network-coop/releases/tag/v0.0.6) |
| LEGO Star Wars: The Complete Saga | In development | [Progress and tasks](https://github.com/dakkaboy/lego-network-coop/milestone/2) | — |
| LEGO Indiana Jones: The Original Adventures | Planned | [Milestone](https://github.com/dakkaboy/lego-network-coop/milestone/3) | — |
| LEGO Indiana Jones 2: The Adventure Continues | Planned | [Milestone](https://github.com/dakkaboy/lego-network-coop/milestone/4) | — |

Each game lives in its own directory under `games/` and builds independently. Keep executable addresses, hooks, game state, protocol layouts and packaging with the game that owns them. The `common/` directory contains reusable code, starting with controller button presses and holds.

## Contribute

Fix a bug, improve the network code, or help add support for another LEGO game. Open an issue to discuss a change or send a pull request. For a new game, start with its own directory under `games/`.
