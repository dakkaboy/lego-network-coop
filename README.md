# LEGO Network Co-op

Windows network co-op mods for LEGO games.

| Game | Status | Download |
| --- | --- | --- |
| [LEGO Star Wars III: The Clone Wars](games/lego-star-wars-iii) | 0.0.1 alpha | [Nexus Mods](https://www.nexusmods.com/legostarwars3theclonewars/mods/28) |

Each game lives in its own directory under `games/` and builds independently. Keep executable addresses, hooks, game state, protocol layouts and packaging with the game that owns them. Extract shared code when a second game has a concrete use for it.

## Contribute

Fix a bug, improve the network code, or help add support for another LEGO game. Open an issue to discuss a change or send a pull request. For a new game, start with its own directory under `games/`.
